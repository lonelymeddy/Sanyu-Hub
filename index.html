Query regional content using the country parameter (ug for Uganda, ke for Kenya) with zero cross-country catalog bleeding.

country=ug | country=ke

Quickstart & Code Examples

Make your first API request in seconds using cURL, JavaScript, or Python.

cURL 
curl -X GET "https://sanyuhub.com/api/movies?country=ug&limit=10" \
  -H "Accept: application/json"
JavaScript (Fetch) 
async function fetchMovies() {
  const response = await fetch('/api/movies?country=ug&limit=10');
  const data = await response.json();
  console.log('Movies retrieved:', data.movies);
}

fetchMovies();
Python (requests) 
import requests

url = "https://sanyuhub.com/api/movies"
params = {"country": "ug", "limit": 10}

response = requests.get(url, params=params)
movies = response.json()
print(f"Total Movies: {movies['total']}")
