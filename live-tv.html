Live TV & Radio API Reference

Access live HLS broadcast streams (.m3u8), EPG schedule data (/api/live-tv/epg/:id), and concurrent viewer counts (/api/live-tv/viewers/:id).

Retrieve channels and radio station manifests filtered by country code.

curl -X GET "https://sanyuhub.com/api/live-tv/channels?country=ug" \
  -H "Accept: application/json"
