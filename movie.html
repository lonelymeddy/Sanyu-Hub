Movie Detail Endpoint Reference

Retrieve individual movie metadata, VJ translator details, genres, and stream proxy URLs.

GET /api/movies/:id
Returns detailed movie information by movie ID.

Path Parameters

Parameter Type Status Description
id string Required Unique identifier of the target movie.

Example Request

curl -X GET "http://localhost:3000/api/movies/1"
