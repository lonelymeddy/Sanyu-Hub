Movies API Reference

Retrieve localized movie catalogues, VJ translations, dubbed content metadata, and API-managed stream proxy URLs.

Canonical Base URL
http://localhost:3000
GET /api/movies
Retrieve a paginated catalogue of movies filtered by country market, VJ translator name, genre, or keyword.

Query Parameters

Parameter Type Status Description
country string Optional Country market code (ug for Uganda, ke for Kenya). Default: ug.
search string Optional Text search keyword matching movie title, overview, or VJ translator name.
vj string Optional Filter by VJ translator (e.g. DJ Mark, VJ Junior, VJ Ice P).
genre string Optional Filter catalogue by genre category (e.g. Action, Sci-Fi).
page integer Optional Page number for pagination. Default: 1.
limit integer Optional Number of records per page. Default: 24, Max: 100.

Example Request

curl -X GET "http://localhost:3000/api/movies?country=ug&vj=DJ%20Mark&limit=10" \
  -H "Accept: application/json"

GET /api/movies/:id
Retrieve detailed metadata, translated title, VJ information, and proxy stream links for an individual movie by ID.
GET /api/stream/movie/:id
Streams movie audio/video through Meddy API managed proxy, enforcing proper CORS headers and partial content ranges.
