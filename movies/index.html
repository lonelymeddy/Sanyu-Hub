Movies API Reference

Discover, search, filter, and integrate Meddy API's movie catalog into external applications. Access complete metadata, VJ narration information, localized Luganda & Swahili titles, and verified streaming assets.

GET /api/movies
Status: 200 OK

1. All Movies Catalog

Retrieve a paginated catalog of movies from the Meddy API backend. Supports multi-field search, filtering by VJ, genre, release year, and sorting.

Query Parameters

Parameter Type Presence Description & Example
country string Optional Country code for localized catalog. Default: ug. Options: ug, ke.
search string Optional Search keyword matching title, VJ name, or synopsis. e.g. search=superman
vj string Optional Filter by specific VJ translator. e.g. vj=VJ Junior or vj=DJ Mark
genre string Optional Filter by genre category. e.g. genre=Action
year integer Optional Filter by release year. e.g. year=2024
sort string Optional Sorting order: recently-added, title, year, rating.
page integer Optional Page number for pagination. Default: 1.
limit integer Optional Number of items per page (Max: 100). Default: 24.
GET /api/movies/{movie_id}

3. VJs & Narration Catalogs

Meddy API indexes translated movies by their narrating VJ. Discover movies narrated by VJ Junior, VJ Emmy, VJ Jingo, DJ Mark, and VJ Ice P.

GET /api/movies?vj=VJ+Junior

4. Languages & Localization

Explicitly distinguishes between Luganda, Lusoga, and Swahili narration tracks. Audio languages and translation credits are preserved per catalog record.

Supported Codes: ug-luganda, ke-swahili

5. Movie Metadata Reference Table

Comprehensive definition of all movie object fields exposed by the Meddy API.

Field Type Description
id string Unique immutable identifier for the movie record.
title string Title of the movie, including VJ translator attribution.
overview string | null Synopsis or summary description.
year integer | null Release year of the movie.
quality string Video resolution badge (e.g., HD, 1080p, 4K).
vj string Narrating VJ / Translator name.
genres array<string> List of assigned genre tags.
mediaUrl string Direct stream manifest or proxied media URL.
