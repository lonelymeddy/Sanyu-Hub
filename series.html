Series API Reference

Retrieve TV series catalogues, season lists, episode details, artwork, and episode stream proxy endpoints.

Canonical Base URL
http://localhost:3000
GET /api/series
Retrieve paginated list of series with season and episode metadata.

Query Parameters

Parameter Type Status Description
country string Optional Country market code (ug, ke). Default: ug.
search string Optional Search keyword matching series title or overview.
page integer Optional Page number. Default: 1.

Example Request

curl -X GET "http://localhost:3000/api/series?country=ug"
GET /api/series/:id
Retrieve full details, season breakdown, and episode listings for a specific series.
GET /api/stream/series/:id
Proxies series episode video stream by episode ID.
