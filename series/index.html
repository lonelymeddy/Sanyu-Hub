Series API Reference

Query multi-season translated series, season breakdowns, episode titles, VJ narration credits, and streaming links.

GET /api/series /api/series/{id}
Status: 200 OK

Fetch series items or individual series details including total seasons, episode counts, and episode streaming references.

cURL Request Example 
curl -X GET "https://sanyuhub.com/api/series?country=ug&limit=10" \
  -H "Accept: application/json"
